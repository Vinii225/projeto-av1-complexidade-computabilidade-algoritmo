PROJETO AV01 - VERSÃO DIVIDIDA EM CLASSES

Arquivos:
- main.cpp       -> ponto de entrada
- Entrada.h/.cpp -> leitura e validação
- Vetor.h/.cpp   -> classe Vetor
- Matriz.h/.cpp  -> classe Matriz
- Cubo.h/.cpp    -> classe Cubo
- Algoritmos.h/.cpp -> 5 funções avaliadas
- Menu.h/.cpp    -> menu e integração

COMPILAÇÃO (g++):
g++ -std=c++17 -Wall -Wextra -O2 main.cpp Entrada.cpp Vetor.cpp Matriz.cpp Cubo.cpp Algoritmos.cpp Menu.cpp -o ProjetoHerriot

EXECUÇÃO:
Windows: ProjetoHerriot.exe
Linux/macOS: ./ProjetoHerriot
